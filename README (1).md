DATA DESIGN

Vehicle catalog: 5000+ generated entries with class, power, weight, grip and economy price.
Classes include pickup, sportcar, SUV, tank, rally, buggy, muscle, van, truck, classic, supercar and offroad.
Do not use real-world trademarks/logos in the generated catalog unless you have licenses.

Zones: 4 seasons x 8 zones = 32 base zones. Each zone can be expanded with deterministic seeds into many tracks.
Surface types: grass, sand, mud, snow, stone, water, gravel.
Dynamic events: rain, mud, heat, tire temperature, traction changes, snow/ice.

Economy:
100 coins = 1 diamond.
Vinyls/decal layers start at 1 coin and scale by rarity.
Pneuma/tire grades use diamonds.
Nitro tier range: 5 diamonds to 1,500,000 diamonds.

Marketplace:
Never implement client-trusted currency. A real online market requires an authoritative backend,
transaction IDs, inventory ownership checks, rate limits, moderation, and rollback handling.
